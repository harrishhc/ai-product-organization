# Products

One folder per product, holding that product's context only: strategy, users, research, decisions, roadmap, experiments, current state.

PDM Core must contain no product-specific assumptions — see [`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) §6. When PDM works on a product, the effective working context is: PDM Core + the selected Product Context.

```
  <product-b>/
```
