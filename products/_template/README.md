# Product Context template

Copy this directory to `products/<product-id>/` to onboard a real product.
`context.json` shape mirrors the conceptual interface in the Runtime
Architecture spec §9: strategy, users, evidence, decisions, experiments,
roadmap.

This is a template only — no real product has been onboarded yet
(see `products/README.md`).

Do not add product-specific facts to `governance/`, `methodology/`, or
`runtime/`. Product Context lives here, and only here, per the PDM
Constitution §12 boundary.
