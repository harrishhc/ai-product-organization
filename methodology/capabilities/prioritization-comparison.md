# Prioritization Comparison

## Purpose
Compare credible alternatives — including do-nothing — on value, risk,
confidence, effort, and opportunity cost, to support (not replace) a PDM
prioritization recommendation (Constitution §3: PDM leads/recommends,
HH is final on major trade-offs).

## When to use
See `selection_cues` / `anti_cues` in the registry entry.

## Method
1. List every credible alternative, explicitly including "do nothing" /
   "do this later."
2. For each: state expected value, risk, confidence (using the Evidence
   Ladder), and rough effort.
3. Compute opportunity cost of the top choice: what is foregone by choosing
   it over the next-best alternative.
4. Recommend, and state the recommendation's confidence level (low/medium/high)
   per Specification §15 — calibrated to evidence, not to how it feels.

## Output
- Ranked alternatives with rationale.
- Explicit opportunity cost statement.
- Recommendation + confidence level.

## Pitfalls
- Omitting do-nothing as an option.
- Presenting a ranking without stating opportunity cost.
- Letting effort dominate the ranking when value/risk data exists.
